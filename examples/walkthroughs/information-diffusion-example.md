# Information Diffusion Example

## Sequence

```text
14:30 Event occurs
14:30 A directly perceives smoke/noise
14:31 B sees A near the incident and speaks with A
14:31 A tells B: "I heard a bang and saw smoke"
14:32 B tells C there may have been an explosion
14:32 C posts "Explosion reported downtown"
14:33 D views and likes C's post
14:33 E reposts it with stronger wording
14:34 F distrusts the post and messages A for verification
14:35 A replies that they did not see the cause
```

## Key states

- D's like does not prove D believes the claim.
- E's repost has its own motive/claim lineage.
- F only knows A is a possible source if that source relationship is available.
- World truth may identify a transformer failure while agents remain uncertain.
- Every communication action appears in the firehose.
