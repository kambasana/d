# Domain Model

World entities, agents, space, time, information, groups, resources, and humanistic systems.

## Documents

- [AWG-DOM-001 — Canonical World Model and Ontology](canonical-world-model-and-ontology.md) — Normative; Define stable identities, entities, relationships, lifecycles, temporal semantics, spatial semantics, and provenance classes.
- [AWG-DOM-002 — Spatial World, Mobility, and Building Specification](spatial-world-mobility-and-building-specification.md) — Normative; Define authoritative geography, OSM-derived topology, gazetteer semantics, routing, journeys, buildings, interiors, occupancy, and synthetic-world spatial rules.
- [AWG-DOM-003 — Agent Runtime, Cognition, and Action Model](agent-runtime-cognition-and-action-model.md) — Normative; Define a proven NPC-style agent stack using perception, blackboards, needs, schedules, utility systems, planners, action executors, and bounded language models.
- [AWG-DOM-004 — Information, Trust, Provenance, and Social Diffusion Model](information-trust-and-provenance-model.md) — Normative; Define claims, observations, beliefs, evidence, contextual trust, information mutation, bad actors, fact-checking, and virtual social-media diffusion.
- [AWG-DOM-005 — Organization, Group, and Institution Model](organization-group-and-institution-model.md) — Normative; Define persistent households, teams, communities, factions, organizations, institutions, governments, membership, authority, and collective action.
- [AWG-DOM-006 — Economy, Resource, and Ownership Model](economy-resource-and-ownership-model.md) — Normative; Define resources, inventories, transactions, assets, ownership, scarcity, markets, obligations, and economic event provenance.
- [AWG-DOM-007 — Stochasticity, Noise, and Randomness Model](stochasticity-noise-and-randomness-model.md) — Normative; Define bounded variation, typed uncertainty, random streams, reproducible seeds, perception noise, memory noise, travel variation, and ensemble analysis without using randomness to disguise missing mechanisms.
- [AWG-DOM-008 — Temporal Model and Simulation Clock](temporal-model-and-simulation-clock.md) — Normative; Define simulation time, wall-clock time, event time, valid time, processing time, schedules, durations, recurrence, causality, and time-zone handling.
- [AWG-DOM-009 — Perception, Sensing, and Observation Model](perception-sensing-and-observation-model.md) — Normative; Define how physical, digital, institutional, and communication channels create bounded observations for agents.
- [AWG-DOM-010 — Object Affordance, Reservation, and Smart Object Model](object-affordance-reservation-and-smart-object-model.md) — Normative; Define objects and places as stateful providers of typed interactions, capacity, ownership, reservations, slots, durations, and observable consequences.
- [AWG-DOM-011 — Human State, Needs, Health, and Life Model](human-state-needs-health-and-life-model.md) — Normative; Define bounded humanistic state for needs, fatigue, health, emotion, roles, obligations, habits, preferences, skills, and life events.
- [AWG-DOM-012 — Population Synthesis, Cohorts, and Individual Instantiation](population-synthesis-cohorts-and-instantiation.md) — Normative; Define creation of aggregate populations, calibrated cohorts, scheduled individuals, cognitive agents, and promotion or demotion between fidelity levels.
- [AWG-DOM-013 — Communication and Virtual Social Platform Model](communication-and-virtual-social-platform-model.md) — Normative; Define face-to-face, phone, message, group, email, broadcast, news, forum, and social-platform channels plus feed, ranking, privacy, moderation, and interaction actions.
