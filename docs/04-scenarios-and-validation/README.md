# Scenarios and Validation

Experiments, run records, calibration, metrics, uncertainty, and counterfactuals.

## Documents

- [AWG-SCN-001 — Scenario Definition and Experiment Protocol](scenario-definition-and-experiment-protocol.md) — Normative; Define versioned scenario packages, initial state, seeds, interventions, measurements, stop conditions, run records, and reproducible branches.
- [AWG-SCN-002 — Validation, Calibration, and Benchmark Framework](validation-calibration-and-benchmark-framework.md) — Normative; Separate software verification, model validation, empirical calibration, human comparison, uncertainty analysis, and use-specific accreditation.
- [AWG-SCN-003 — Uncertainty and Sensitivity Analysis](uncertainty-and-sensitivity-analysis.md) — Normative; Define ensembles, seed variation, parameter sensitivity, model-provider sensitivity, confidence intervals, and reporting of unstable outcomes.
- [AWG-SCN-004 — Scenario Comparison and Counterfactual Analysis](scenario-comparison-and-counterfactual-analysis.md) — Normative; Define baseline alignment, branch inheritance, divergence analysis, causal comparison, and safeguards against false counterfactual claims.
- [AWG-SCN-005 — Example Scenario Package](example-scenario-package.md) — Informative; Provide an informative example showing how a bounded, reproducible scenario package should be assembled.
- [AWG-SCN-006 — Experiment Reproducibility and Run Record](experiment-reproducibility-and-run-record.md) — Normative; Define the immutable record needed to reconstruct a run, including inputs, versions, seeds, plugins, models, datasets, interventions, snapshots, and outputs.
- [AWG-SCN-007 — Metrics, Measurements, and Outcome Catalog](metrics-measurements-and-outcome-catalog.md) — Normative; Define measurement semantics, units, windows, populations, denominators, uncertainty, provenance, and branch-comparison compatibility.
- [AWG-SCN-008 — Scenario Cards, Model Cards, and Limitations](scenario-cards-model-cards-and-limitations.md) — Normative; Define concise disclosure artifacts for scenarios, agent policies, AI models, datasets, validation scope, risks, and prohibited interpretations.
- [AWG-SCN-009 — Data Calibration and Parameter Estimation Protocol](data-calibration-and-parameter-estimation-protocol.md) — Normative; Define calibration datasets, train/validation separation, parameter fitting, objective functions, identifiability, overfitting controls, and recalibration.

## Reading rule

Read the Simulation Constitution and controlled vocabulary before treating any document in this area as implementation authority.
