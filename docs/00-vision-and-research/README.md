# Vision and Research

Product intent, boundaries, evidence, prior art, and design principles.

## Documents

- [AWG-VIS-001 — Product Vision](product-vision.md) — Informative; Define the product vision for a geographically grounded, persistent, modular agentic world operating system.
- [AWG-VIS-002 — Product Scope and Non-Goals](product-scope-and-non-goals.md) — Normative; Bound the platform so that it is not mistaken for a chatbot village, omniscient digital twin, or guaranteed prediction engine.
- [AWG-VIS-003 — Design Principles](design-principles.md) — Normative; Set the cross-cutting design principles used by architecture, product, simulation, research, and UI work.
- [AWG-VIS-004 — Research and Prior Art](research-and-prior-art.md) — Informative; Preserve the research review of agent simulations, game AI, agent-based modelling, geospatial systems, and reusable open-source components.
- [AWG-VIS-005 — Research Method and Evidence Quality](research-method-and-evidence-quality.md) — Normative; Define how papers, repositories, game-AI patterns, standards, datasets, and empirical claims are collected, graded, cited, and revisited.
- [AWG-VIS-006 — Architecture Pattern Reuse Policy](architecture-pattern-reuse-policy.md) — Normative; Define how established game, simulation, geospatial, distributed-systems, and AI patterns are adopted without copying unsuitable implementations.

## Reading rule

Read the Simulation Constitution and controlled vocabulary before treating any document in this area as implementation authority.
