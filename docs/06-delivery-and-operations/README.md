# Delivery and Operations

MVP plan, testing, performance, reliability, releases, migrations, and supply chain.

## Documents

- [AWG-OPS-001 — MVP Roadmap and Definition of Done](mvp-roadmap-and-definition-of-done.md) — Normative; Define a phased path from one offline district and deterministic movement through bounded AI, information space, validation, and multi-resolution scale.
- [AWG-OPS-002 — Software Testing and Quality Strategy](software-testing-and-quality-strategy.md) — Normative; Define unit, property, invariant, contract, integration, replay, performance, security, offline, migration, and accessibility testing.
- [AWG-OPS-003 — Performance Budget and Capacity Plan](performance-budget-and-capacity-plan.md) — Normative; Define measurable budgets for agents, events, AI calls, map rendering, storage, replay, snapshots, recovery, and offline hardware profiles.
- [AWG-OPS-004 — Observability, Reliability, and Recovery](observability-reliability-and-recovery.md) — Normative; Define service telemetry separately from simulation events, health indicators, failure isolation, degraded modes, recovery, and auditability.
- [AWG-OPS-005 — Release and Versioning Strategy](release-and-versioning-strategy.md) — Normative; Define document, schema, plugin, scenario, data, and model versioning plus release manifests, checksums, migrations, and deprecation.
- [AWG-OPS-006 — Developer Environment and Contributor Workflow](developer-environment-and-contributor-workflow.md) — Normative; Define local, Docker, offline, branch, pull-request, review, formatting, validation, and release workflows.
- [AWG-OPS-007 — Data Migration and Backward Compatibility](data-migration-and-backward-compatibility.md) — Normative; Define migrations for schemas, events, snapshots, scenarios, plugins, projections, datasets, and model records.
- [AWG-OPS-008 — Backup, Restore, and Disaster Recovery](backup-restore-and-disaster-recovery.md) — Normative; Define backup scopes, recovery point and time objectives, snapshot consistency, restore testing, offline media, and corruption recovery.
- [AWG-OPS-009 — Documentation Quality Gates](documentation-quality-gates.md) — Normative; Define structural, semantic, traceability, link, schema, example, licensing, provenance, and release validation for the pack.
- [AWG-OPS-010 — Linear Project and Execution Mapping](linear-project-and-execution-mapping.md) — Normative; Define how the canonical disk or Git repository maps to the existing AWG Linear project, milestones, issues, branches, reviews, and delivery status.
- [AWG-OPS-011 — Software Supply Chain and Dependency Assurance](software-supply-chain-and-dependency-assurance.md) — Normative; Define dependency intake, SBOMs, signatures, vulnerability review, licence review, pinning, reproducible builds, and plugin provenance.

## Reading rule

Read the Simulation Constitution and controlled vocabulary before treating any document in this area as implementation authority.
