# Governance and Safety

Constitution, security, privacy, responsible use, retention, and change control.

## Documents

- [AWG-GOV-001 — Simulation Constitution and Invariants](simulation-constitution-and-invariants.md) — Normative; Define the non-negotiable laws that no model, plugin, scenario, operator, projection, or user interface may bypass.
- [AWG-GOV-002 — Security, Safety, Privacy, and Misuse Model](security-safety-privacy-and-misuse-model.md) — Normative; Define threat boundaries, privacy controls, misuse protections, access rules, and high-consequence scenario restrictions.
- [AWG-GOV-003 — Governance, Change Control, and Approvals](governance-change-control-and-approvals.md) — Normative; Define document authority, decision ownership, change classes, reviews, approvals, emergency changes, and audit records.
- [AWG-GOV-004 — Data Classification, Retention, and Deletion](data-classification-retention-and-deletion.md) — Normative; Define data classes, retention rules, deletion semantics, archival boundaries, backups, and treatment of immutable simulation history.
- [AWG-GOV-005 — Human Subjects and Real-Person Representation Policy](human-subjects-and-real-person-policy.md) — Normative; Define protections for simulations derived from interviews, personal records, identifiable individuals, or sensitive population data.
- [AWG-GOV-006 — Claims, Communication, and Responsible Use Policy](claims-communication-and-responsible-use-policy.md) — Normative; Control how simulation results, uncertainty, forecasts, synthetic populations, and causal findings are described to users and stakeholders.
- [AWG-GOV-007 — Compliance, Audit, and Evidence Retention](compliance-audit-and-evidence-retention.md) — Normative; Define audit events, evidence packages, access reviews, approval records, reproducibility bundles, and compliance reporting.

## Reading rule

Read the Simulation Constitution and controlled vocabulary before treating any document in this area as implementation authority.
