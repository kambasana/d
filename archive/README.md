# Archive

This area preserves conversation-derived source documents and immutable release snapshots for traceability. Archived files are informative historical inputs, not current normative authority.

The Git working tree is the canonical v0.2.0 documentation and contract pack. `releases/agentic-world-graph-v0.2.0.zip` is the imported release projection of that pack; `releases/agentic-world-graph-master-pack-v0.1.0.zip` is retained for v0.1.0 context. Do not treat either ZIP as the working tree.

Changes must follow `AGENTS.md`: Simulation Constitution, accepted ADRs, and authored specs/registers/contracts are the source of truth. Do not edit `generated/` by hand.
