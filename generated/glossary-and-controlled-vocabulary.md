# Glossary and Controlled Vocabulary

Generated from `registers/glossary.yaml`.

## Adapter

A replaceable implementation of a stable capability contract.

**Allowed synonyms:** connector

**Do not use interchangeably with:** plugin implementation

## Agent

A persistent simulated actor with identity, state, constraints, history, perception, goals, and executable actions.

**Allowed synonyms:** NPC, simulated person

**Do not use interchangeably with:** LLM, user account, cohort

## Analytical cluster

A visual grouping created by a query or filter rather than physical co-location.

**Do not use interchangeably with:** geographic cluster, co-location cluster

## Belief

An agent-specific disposition toward a claim, including confidence, uncertainty, provenance, and contradiction state.

**Do not use interchangeably with:** world truth

## Branch

A scenario-run lineage that inherits state at a branch point and then diverges through declared changes and consequences.

**Do not use interchangeably with:** copy

## Building

A spatial entity with geometry, entrances, occupancy areas, and optional floors, rooms, routes, and affordances.

**Do not use interchangeably with:** place name

## Claim

A proposition carried through observation or communication with source and lineage.

**Do not use interchangeably with:** fact

## Co-location cluster

A visual grouping of agents occupying the same place, room, vehicle, entrance, or near-identical coordinate.

**Do not use interchangeably with:** geographic cluster

## Command

A typed request for a state-changing operation that is validated before execution.

**Do not use interchangeably with:** event, intent

## Counterfactual

A branch comparison that changes declared conditions after a common baseline; it is not proof of real-world causality by itself.

**Do not use interchangeably with:** prediction

## Event

An immutable record that something occurred or was rejected at a defined simulation time and sequence.

**Do not use interchangeably with:** command

## Evidence

An observation, record, message, measurement, or source used to support or challenge a claim.

**Do not use interchangeably with:** belief

## Firehose

The structured, ordered stream of domain events emitted by worlds, agents, groups, infrastructure, and information systems.

**Allowed synonyms:** event stream

**Do not use interchangeably with:** software log

## Gazetteer

A system that resolves named places and addresses to geographic entities and geometry references.

**Do not use interchangeably with:** routing engine

## Geographic cluster

A visual aggregation of agents distributed within a screen-space or map area.

**Do not use interchangeably with:** co-location cluster

## Information space

The network of claims, messages, posts, media, channels, audiences, platforms, and exposures connected to the physical world.

**Do not use interchangeably with:** global knowledge

## Intent

A proposed goal or desired action before typed command creation and validation.

**Do not use interchangeably with:** command, event

## Journey

A time-consuming movement process from origin to destination using one or more routes and transport legs.

**Do not use interchangeably with:** teleport

## LLM

A language model used through bounded adapters for defined reasoning or language tasks.

**Allowed synonyms:** language model

**Do not use interchangeably with:** agent, simulation kernel

## Observation

A bounded record made available to an agent through a valid physical, digital, institutional, or communication path.

**Do not use interchangeably with:** world state

## Place

A stable spatial identity linked to one or more geometries, names, relationships, access rules, and provenance.

**Do not use interchangeably with:** coordinate

## Plugin

A packaged extension that declares capabilities, permissions, versions, dependencies, and compatibility.

**Do not use interchangeably with:** core contract

## Projection

A derived read model used for maps, dashboards, search, analytics, feeds, or other views.

**Do not use interchangeably with:** authoritative state

## Provenance

The lineage explaining origin, transformations, sources, actors, times, and derivations of data, claims, events, or artefacts.

**Do not use interchangeably with:** citation only

## Random stream

A named, owned sequence of stochastic values with a seed or recorded position.

**Do not use interchangeably with:** unexplained noise

## Replay

Reconstruction of a run from recorded inputs, versions, random streams, events, snapshots, and model outputs.

**Do not use interchangeably with:** rerun with new model calls

## Scenario

A versioned package of world state, population, assumptions, configuration, events, interventions, measurements, and stop conditions.

**Do not use interchangeably with:** prompt

## Semantic zoom

A visualization strategy that changes what information is shown as scale changes, rather than only resizing the same marks.

**Do not use interchangeably with:** marker scaling

## Simulation level of detail

The fidelity at which a population, cohort, individual, or local embodied agent is simulated.

**Allowed synonyms:** simulation LOD

**Do not use interchangeably with:** visualization LOD

## Simulation time

The authoritative temporal coordinate for world causality.

**Do not use interchangeably with:** wall-clock time

## Smart object

An object or place exposing typed affordances, slots, preconditions, capacity, reservations, and effects.

**Do not use interchangeably with:** decorative prop

## Snapshot

A versioned state checkpoint used with event history for recovery or replay.

**Do not use interchangeably with:** event history replacement

## Synthetic geography

Generated but coherent spatial data using explicit topology, places, geometry, access, routing, and provenance.

**Do not use interchangeably with:** invented place names

## Telemetry

Software-operational measurements such as latency, CPU, memory, queue depth, and errors.

**Do not use interchangeably with:** domain event

## Trust

An agent-specific, domain- and context-dependent evaluation of a source based on relationships, history, and evidence.

**Do not use interchangeably with:** single universal score

## Visualization level of detail

The representation used at the current view scale, such as heatmap, cluster, marker, or detailed avatar.

**Allowed synonyms:** visualization LOD

**Do not use interchangeably with:** simulation LOD

## Wall-clock time

Real processing or user-interface time outside the simulated world chronology.

**Do not use interchangeably with:** simulation time

## World

A persistent spatial-temporal state containing entities, systems, rules, histories, and branches.

**Do not use interchangeably with:** map

## World truth

The authoritative simulated state and events, distinct from any agent belief or UI projection.

**Allowed synonyms:** authoritative state

**Do not use interchangeably with:** belief
